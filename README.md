# Series Summation

Programs to compute the summation of the series 1 + X + X² + X³ + … using different approaches.

---

## 📖 Concepts
- Brute force iteration (O(n))
- Mathematical formula (O(1))
- Divide and conquer (O(log n))

---

## 🛠️ Technologies
- Python 3.x / C++ (depending on implementation)

---

## 🚀 Future Improvements
- Handle very large exponents
- Compare runtime for different approaches
